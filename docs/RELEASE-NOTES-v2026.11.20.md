# padavan-tw v2026.11.20（第一個正式版）

支援機型：**Newifi D3**（`NEWIFI3`，Breed 刷入，已實機驗證）、**小米 CR6608**（`CR660x`，**尚未實機測試**）。每個機型有標準版（880 MHz）與 `-oc1000` 超頻版（1000 MHz）；不確定就用標準版。刷機前請比對 `SHA256SUMS`。

## 重點

### Wi-Fi 穩定性
- **修正 2.4G 每隔一陣子中斷約 50 秒**（D3）：根因是 4.4 核心新配置的 skb 沒有清掉硬體 NAT 的殘留標記，本機送出的封包被誤送進 PPE，有線埠的 STP 封包變成「2.4G 收到自己的封包」而被判定迴圈。修正後同條件 60 分鐘 0 次（修正前 30 分鐘 2 次）。已回報 TurBoTse/padavan#33、hanwckf/padavan-4.4#73
- **Wi-Fi 重新啟動後立刻恢復連線**（急速連線）：原本 STP 要等 30 秒，裝置在這段時間連上會拿不到 IP（Windows 顯示「沒有網際網路」好幾分鐘）。STP 計時也縮短成 8 秒
- **Wi-Fi 迴圈保護**：Wi-Fi 介面的 STP 封包預設擋掉；某個頻段收到其他裝置的 STP 封包（家裡有橋接器、中繼器）時，只有那個頻段自動改回標準保護，並寫進系統記錄
- 5G 頻寬 40／80 MHz 時自動選頻不選 165（選到會掉成 20 MHz）；國碼台灣時 2.4G 自動選頻不選 12、13
- **5G 出廠預設值**：80 MHz、自動選頻、TxBurst 開、HT 運作模式改成混合（關閉 Greenfield）。D3 兩晚 15 輪實測：Greenfield 關 5 輪 0 次斷線、開著 5 輪 1 次斷線，TxBurst 關最差
- **2.4G 出廠預設值**：維持 20 MHz、TxBurst 開。40 MHz 較快，但共存偵測（HT_BSSCoexistence）是關的（鄰近 AP 多時不會自動退回 20 MHz），所以不預設開；2.4G 預設是 b/g/n 混合，驅動實際套用的 HT 運作模式就是混合（Greenfield 只在純 N 模式生效）
- 沒有原廠 TxBF 校正資料的機型（例如 D3）不再顯示 TxBF 選項（設了也無效）

### 網路
- **自動 NAT66**：接在另一台路由器後面、上一層沒有可分配的 IPv6 前綴時，區網自動改用 NAT66（網際網路頁可關閉）
- **中華電信 MOD 自動設定**：自動偵測機上盒接在哪個 LAN 孔（看機上盒要位址時帶的 `CHT-` 識別，再比對各孔的廣播計數），偵測到就把那個孔設成 MOD 專用孔、寫進系統記錄；網際網路頁新增「MOD／IPTV 接法」卡片（自動偵測開關、手動選孔、MOD＋VLAN、群播設定）。有 MOD 孔時 WAN 設成交換器 IGMP 的固定上游孔，修正直播黑畫面。D3 實測：機上盒重開後約 1～2 分鐘偵測到、直播正常（約 10 Mbps 只送到 MOD 孔，其他 LAN 孔不會被群播灌滿）、換台正常（實測多台）
- **igmpproxy**：修正群組過期時當機（use-after-free，上游 PR #98 的修法）；區網送出的群播不再被當成上游來源。IGMP 代理預設維持開啟
- 黑潮 DNS **3.4.0**：新增串接模式（預設開）——前面還有一台跑黑潮 DNS 的路由器時，直接共用它的評測結果，依黑潮的設計，主路由器不能用時會退回自己的評測與加密上游、回來後自動接回（本專案還沒實測這個情況）；包含 3.3.6／3.3.7 的路徑檢查（分辨上游壞了和路上有人動手腳）、一般 DNS 被接走時不再拿來評測、沒有 IPv6 時不再試 IPv6 上游；路由器 IPv6 關閉時自動告訴黑潮。D3 壓測每秒 40 筆查詢 0 逾時

### 其他
- 刷機寫完由 init 直接重開，不再卡在「重開中」
- 硬體 QoS（QDMA）捨棄：實測 CPU 約 3 倍、延遲沒有改善
- 診斷頁新增「Wi-Fi 迴圈保護」：開關，以及攔截紀錄（Wi-Fi 收到的 STP 封包數、改回標準保護的頻段、最近幾次觸發的原因）

## 已知限制
- Linux 4.4 核心已停止官方維護，不建議把管理頁面或 SSH 開放到 WAN
- 閉源 Wi-Fi 驅動沒有空中時間公平（airtime fairness），多台裝置同時滿載時延遲會變高
- 部分 USB Wi-Fi 網卡（例如 AIC8800）在 D3 上大量上傳時可能斷線、上傳速度常常是 0（3.4、4.4 都會，驅動相容性問題）
- MOD 自動偵測要等機上盒重新要位址（機上盒開機）才偵測得到：只重開路由器、機上盒沒重開時，請把機上盒重開一次；偵測到之後不會自動取消 MOD 孔（要在網際網路頁改回）
- 黑潮 DNS 3.4.0 的記憶體會隨快取長大（大量不重複新網域後約 110 MB、閒置不回落），系統記憶體吃緊時會讓出快取；已回報黑潮作者
- 小米 CR6608 尚未實機測試
