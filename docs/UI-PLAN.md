# 後台重構計畫

> 2026-11-13：後台改由本機工作階段負責，新的 UX 設計、資訊架構與資料介面約定見 [HANDOFF-UI.md](HANDOFF-UI.md)，以那份為準。本文件保留作為第一版的紀錄。

設計稿：<https://claude.ai/artifact/RiS7HfJN96jE2s71p3gKXH>（總覽、診斷、裝置詳情、設定頁、手機版、設計語彙）

## 目標

- **UX 優先**：使用者覺得「網路怪怪的」時，後台要能回答「哪裡有問題、為什麼、怎麼辦」，而不是只列數字。
- **統一設計語彙**：所有頁面共用同一套顏色、字級、間距、元件、狀態規則與寫法（見設計稿「設計語彙」）。
- **手機也能看懂資訊**：不只是縮小或堆疊。表格在手機上改成有標籤的卡片，圖表與關鍵數字保留，可點區域至少 44 px。
- **不疊特效**：沒有漸層、沒有厚陰影、沒有動畫裝飾。卡片用細框線分層。
- **輕量**：不用前端建置工具，純 JS／CSS；不載入外部字型與 CDN（路由器可能還沒連上網）。

## 現況

- 84 個設定頁共用同一個骨架：`.wrapper` → 頂部（logo + `#TopBanner`）→ `form` → 左欄（`#mainMenu`、`#subMenu`）＋右欄（`.box` + `#tabMenu` + 表單表格）→ `#footer`
- 選單、頂部狀態列、頁尾都由 `state.js` 的 `show_banner()`、`show_menu()`、`show_footer()` 產生
- Bootstrap 2.0.3（2012）＋ jQuery 1.8.3，沒有 viewport meta，手機會縮成桌機版
- 儀表板需要的資料大多已經有：`json_system_status()`（CPU、記憶體、運作時間、Wi-Fi 狀態）、`netdev()`（各介面流量）、`wanlink()`（WAN 狀態）、`lan_clients.asp`、無線用戶端清單、rstats 歷史流量

## 做法：換框架與主題，不重寫 84 頁

上游的 `.asp` 頁面盡量不改，方便之後同步 TurBoTse：

1. **主題樣式 `bootstrap/css/tw.css`**：設計語彙的 CSS 變數（亮色／暗色依系統自動切換），並重新定義舊頁面用到的 Bootstrap 2 class（`span*`、`row-fluid`、`table`、`btn`、`input-*`、`nav-tabs`、`alert`、`well`…），讓 84 頁一次換上新外觀並支援 RWD。
2. **編譯時注入**：`www/Makefile` 安裝網頁時，在每個 `.asp` 的 `main.css` 後面插入 viewport meta 與 `tw.css`。原始 `.asp` 檔不用改。
3. **新框架（改 `state.js`）**：
   - 桌機：左側固定選單、頂部精簡狀態列（CPU、記憶體、Wi-Fi 開關、套用、登出、重開機）
   - 手機：頂部列＋選單抽屜、底部分頁列（總覽／診斷／裝置／設定）
   - 手機表格：有表頭的資料表自動加上欄位標籤，改成卡片；設定表（標籤＋欄位）改成標籤在上、欄位在下
4. **新頁面**（新增檔案，不改上游頁面）：總覽儀表板、網路診斷、裝置詳情。
